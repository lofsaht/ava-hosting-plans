## 免备案免掉的是什么，没免掉的是什么

免掉的是备案流程本身。备案要先有域名、再提交资料、等管局审核，个人要准备身份证、手机号、居住信息，企业还要营业执照、法人信息和办公地址核验；涉及医疗、金融、出版这类前置审批的业务，时间更长。服务器放在境外，这套流程不适用，付款开机绑域名，链路能压到当天走完。

没免掉的是两条。

一条是内容审核。境外服务器同样受机房所在地法律约束，违法违规内容会被封停，这一点在几乎所有海外主机商的服务条款里都写着，不是营销话术。免备案不等于想放什么就放什么。

另一条是国内访问质量。备案和能否访问是两件事，会不会被墙取决于 IP 和域名本身有没有被封，跟服务器在不在境外没有直接关系。但物理距离绕不开：机房在欧洲，国内用户访问就要跨整个欧亚大陆，延迟和丢包跟香港、日本机房不是一个量级。

还有一层权衡很少被提。核心用户都在境内、又靠搜索流量吃饭的站，境内服务器虽然要备案，百度收录确实更顺一些。这不是免备案能解决的问题，是选型时要认下的成本。

## 买完之后：从开机到网站能打开

五步能走完，重点在会出错的地方。

1. 下单后在控制面板取三样东西：IP、SSH 端口、root 密码。
2. 本地连上去：`ssh -p 端口 root@你的IP`。Windows 用 Xshell 或 PuTTY，Mac 直接开终端。
3. 装环境。想省事就装宝塔，Debian/Ubuntu 下执行：`wget -O install.sh https://download.bt.cn/install/install-ubuntu_6.0.sh && bash install.sh ed8484bec`，装完会给出面板地址和账号。
4. 域名加一条 A 记录指向服务器 IP，等解析生效。通常几分钟到几小时，没生效就去装 WordPress，安装向导会卡在数据库那一步。
5. 面板里建站、建数据库，上传 WordPress 解压，浏览器访问域名走安装向导。

两个容易踩的点。1GB 内存的机器别装 Apache，用 Nginx 加 PHP-FPM，再配一个缓存插件，日常几百到几千 PV 的博客能稳住；硬上 Apache 大概率在装第二个插件时就 OOM。另外，注册信息和付款 IP 的地区对不上，海外主机商的风控容易判定欺诈并自动退款，下单时把代理关掉。
